# HTML Layout Modes

Use this file when choosing the final HTML presentation.

## `editorial`

Best for:

- AI analysis
- product essays
- high-agency long-form articles

Traits:

- strong hero area
- more pronounced title block
- media/publication feel

## `minimal`

Best for:

- reflective essays
- calm Chinese long-form reading
- text-first pieces

Traits:

- restrained layout
- softer visual hierarchy
- lower decoration

## `bold`

Best for:

- tutorials
- playbooks
- step-by-step guides

Traits:

- stronger section blocks
- clearer instructional hierarchy
- more visual separation between steps
