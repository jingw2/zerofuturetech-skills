# Visual Dimensions

Use this file when defining the thumbnail direction.

## Dimensions

- `type`: `hero`, `conceptual`, `minimal`, `diagrammatic`, `typography`
- `palette`: `elegant`, `cool`, `earth`, `mono`, `vivid`
- `rendering`: `editorial-digital`, `flat-vector`, `diagram`, `painterly`
- `text`: `none`, `title-only`
- `mood`: `subtle`, `balanced`, `bold`

## Default Rules

For most serious articles:

- `type`: `conceptual`
- `palette`: `elegant`
- `rendering`: `editorial-digital`
- `text`: `none`
- `mood`: `balanced`

For tutorials:

- `type`: `diagrammatic`
- `palette`: `cool`
- `rendering`: `diagram`
- `text`: `none`
- `mood`: `balanced`

## Avoid

- hyper-generic AI glow
- random futuristic city scenes
- meaningless abstract blobs
- human faces unless the article is really about a person
- heavy text baked into the image unless explicitly required
